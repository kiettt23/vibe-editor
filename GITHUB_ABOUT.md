## How to Set This Up

1. Go to your GitHub repository: https://github.com/kiettt23/vibe-editor
2. Click on the ⚙️ gear icon next to "About" on the right side
3. Add the description above
4. Add the topics/tags listed
5. Optionally add the website URL: https://vibe-editor-ten.vercel.app
6. Save changes

This will make your repository more discoverable and clearly identify it as a hackathon project.
